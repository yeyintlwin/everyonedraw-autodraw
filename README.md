# Everyone Draw ပုံဆွဲအကူ (Chrome extension)

ပုံတစ်ပုံကို everyonedraw.com ရဲ့ canvas ပေါ်မှာ ဖောက်ထွင်းမြင်ရအောင် ထပ်ပြပေးပြီး
တစ်ရောင်ချင်း ကိုယ်တိုင် ဆွဲဖို့ လမ်းပြပေးတယ်။ **pixel ကို အလိုအလျောက် ချပါမယ်** — အရောင်ရွေးတာ၊ click တာ ကိုယ်တိုင်ပါ။

## Install (တစ်ခါပဲ)

1. Chrome မှာ `chrome://extensions` ကို ဖွင့်ပါ။
2. ညာဘက်အပေါ်က **Developer mode** ကို ဖွင့်ပါ။
3. **Load unpacked** ကို နှိပ်ပြီး ဒီ folder (`everyone-draw`) ကို ရွေးပါ။
4. https://everyonedraw.com ကို ဖွင့် (ဖွင့်ထားပြီးသားဆို reload) — ဘယ်ဘက်မှာ 🎨 ပုံဆွဲအကူ panel ပေါ်လာမယ်။

code ပြင်ပြီးရင် `chrome://extensions` မှာ extension ရဲ့ ↻ (reload) ကို နှိပ်ပြီး site ကို reload ပါ။

## သုံးနည်း

1. **ပုံထည့်** — panel ထဲက ကွက်ကို click ပြီး ပုံရွေး၊ ပုံကို ကွက်ထဲ ဆွဲချ၊ သို့ ပုံကို copy ပြီး site ပေါ်မှာ Ctrl+V။ အကျယ် 32–64 က ဆွဲရလွယ်တယ်။
2. **နေရာ** — site ကို ဆွဲချင်တဲ့နေရာ ရွှေ့ပြီး "screen အလယ်မှာ ထားမယ်" ကို နှိပ်ပါ (သို့ x, y ရိုက်ထည့်)။ ပုံက site ပေါ်မှာ အနီ dashed ဘောင်နဲ့ ပေါ်လာမယ်။
3. **အရောင်ရွေး** — panel ရဲ့ အရောင်စာရင်းက အရောင်တစ်ခုကို ရွေးပါ။ site ရဲ့ ညာဘက် အရောင်တန်းမှာလည်း
   အဲအရောင် အလိုလို ရွေးပြီးသား ဖြစ်မယ်။ ပြောင်းပြန် — site မှာ အရောင်ရွေးရင် (ပုံထဲမှာ ပါတဲ့အရောင်ဆို)
   panel မှာလည်း လိုက်ရွေးမယ်။ အဲအရောင် ဆွဲရမယ့် ကွက်တွေက ထင်ထင်ရှားရှား (zoom ကြီးရင် ဘောင်ခတ်) ပေါ်မယ်။
4. **ဆွဲ** — ဘောင်ခတ်ထားတဲ့ ကွက်တွေကို ကိုယ်တိုင် click ပါ။
   ဆွဲပြီးသား (အရောင်မှန်ပြီးသား) ကွက်တွေကို extension က အလိုလို သိပြီး overlay ကနေ ဖျောက်ပေးတယ်။
5. **တစ်ရောင် auto ဆွဲ** — zoom ≥ 2 မှာ panel ရဲ့ **▶ ဒီအရောင် ဆွဲ** ကို နှိပ်ပါ။ ရွေးထားတဲ့ အရောင်ရဲ့ ကွက်တွေကိုပဲ
   "Click ကြား (ms)" တစ်ခါ တစ်ကွက် click မယ်။ ကျန်တဲ့ကွက်တွေ screen ပြင်ပရောက်ရင် page ကို အဲနေရာ ဖွင့်ပြီး
   (reload) ဆက်ဆွဲမယ်။ အဲအရောင် ပြီးရင် ရပ်မယ် — နောက်အရောင် ရွေးပြီး ▶ ပြန်နှိပ်ပါ။
   - click ပြီးသား ကွက်တွေကို မှတ်ထားတယ် — ■ နဲ့ ရပ်၊ page ပိတ်၊ reload ပြီးရင်တောင် **▶ ဆက်ဆွဲ** နှိပ်ရင် ရပ်ခဲ့တဲ့နေရာက ဆက်မယ်။
   - site ဘက်က data (cooldown၊ pixel ကျ/မကျ) ကို မဖတ်ဘူး — site က cooldown ကြောင့် လက်မခံတဲ့ ကွက်တွေ
     ကျန်ခဲ့ရင် ms ကို တိုးပြီး **ပြန်စ** (ဒီအရောင်ရဲ့ click မှတ်တမ်း ဖျက်) → ▶ ပြန်နှိပ်ပါ။ ဆွဲပြီးသား ကွက်တွေကို ကျော်မယ်။
   - run နေတုန်း site ရဲ့ map ကို မထိပါနဲ့။ အရောင် ပြောင်းရင် (panel ဖြစ်ဖြစ် site ဖြစ်ဖြစ်)၊ ပုံ/နေရာ ပြောင်းရင် ရပ်မယ်။
   - "App အရောင် ၃၂ ရောင်" ထဲက app-only အရောင်တွေကို web site မှာ ရွေးလို့မရလို့ auto မဆွဲနိုင်ဘူး။
6. ကွက်ရှာမတွေ့ရင် **"နောက်တစ်ကွက် ရှာ"** — screen ပေါ်မှာရှိရင် အနီဘောင်နဲ့ ပြမယ်၊ မရှိရင် အဲနေရာကို ခေါ်သွားမယ်။

## မှတ်ချက်

- progress က screen ပေါ်မှာ zoom ≥ 2 နဲ့ မြင်ဖူးတဲ့ ကွက်တွေကိုပဲ စစ်နိုင်တယ်။
- site က update လုပ်ရင် (canvas ဆွဲပုံ ပြောင်းရင်) overlay နေရာ လွဲနိုင်တယ် — ဒါဆို "canvas ကို ရှာနေတယ်…" ပေါ်ပြီး overlay ပျောက်မယ်။
- ပုံနဲ့ progress ကို everyonedraw.com ရဲ့ browser storage မှာ သိမ်းထားတယ်။
